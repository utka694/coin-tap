COIN TAP — инструкция

1. Загрузите эти файлы в новый Node.js проект на Replit.
2. В Replit Secrets добавьте BOT_TOKEN = токен вашего бота от BotFather.
3. Запустите проект командой npm start (Replit обычно запускает её сам).
4. Для локального теста можно установить DEV_MODE=true, но выключите/удалите DEV_MODE перед публикацией.
5. Опубликуйте проект и скопируйте публичный HTTPS URL.
6. В Telegram откройте @BotFather:
   /mybots -> выберите Coin Tap -> Bot Settings -> Menu Button -> Configure menu button
   Укажите HTTPS URL и название, например Play.
7. Откройте бота и нажмите кнопку меню.

Важно:
- Не отправляйте BOT_TOKEN никому и не вставляйте его в исходный код.
- В продакшене не включайте DEV_MODE.
- Это стартовая версия. Перед большим запуском стоит добавить антибот-защиту, резервные копии и более строгие лимиты запросов.
- Монеты здесь виртуальные и не имеют денежной ценности.
